Проверка обновлений

Новые версии из RuStore попадают в общую историю только после подтверждения. Обновлено: __UPDATED__.

Доступ для подтверждения

Чтобы подтверждать и отклонять, нужен GitHub-токен с правом записи в репозиторий (fine-grained, Contents: Read and write, только для репозитория __REPO__). Он хранится только в этом браузере.
